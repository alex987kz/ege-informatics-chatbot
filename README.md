# Учебный чат-бот по подготовке к ЕГЭ по информатике

Проект для кейса № 3 производственной практики в Университете «Синергия». Сценарий связан с [подготовкой школьников к ЕГЭ по информатике](https://synergy.ru/school/podgotovka/ege/informatika). Чат-бот определяет тему вопроса и показывает готовый ответ из учебной базы. Сведения из ответов приведены для демонстрации. Заявка на курс имитируется. Для проверки используйте только вымышленные данные.

[Запустить демонстрацию на сервере](http://93.171.232.233:8000/).

## Локальный запуск

Из распакованной папки с файлом `requirements.txt` выполните команды в терминале с Python 3.12 или 3.14.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m nltk.downloader stopwords
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

В Windows для создания окружения можно использовать `py -m venv .venv`, а в остальных командах — `.venv\Scripts\python.exe`. Если корпус стоп-слов недоступен, приложение использует короткий встроенный список.

Откройте [страницу чата](http://127.0.0.1:8000/). Для проверки задайте вопрос «Какая программа курса?», нажмите «Какие темы?» и отправьте вопрос вне темы, например «Сколько лететь до Марса?».

## Проверка

```sh
.venv/bin/python -m unittest -v
```

Тесты проверяют распознавание вопросов, страницу чата, ответы API и обработку некорректного ввода. Из 13 тестов 12 проходят, один отмечен как ожидаемая ошибка для слова с двумя опечатками.

## Как устроен проект

| Файл | Роль |
| --- | --- |
| `app/main.py`, `app/routes.py`, `app/schemas.py` | Запуск FastAPI, маршруты `GET /` и `POST /chat`, схемы данных |
| `app/nlp.py` | Разбор русской фразы, TF-IDF, поиск по ключевым словам и обработка одной опечатки |
| `app/knowledge.py` | Примеры вопросов, ключевые слова и готовые ответы |
| `templates/index.html`, `static/` | Страница чата, стили и отправка сообщений через JavaScript |
| `tests/` | Тесты NLP и веб-приложения |

Браузер отправляет вопрос в FastAPI. Сервер убирает стоп-слова и приводит слова к основам с помощью инструментов NLTK. TF-IDF и косинусное сходство помогают сопоставить вопрос с примерами. Если близкого примера нет, бот ищет ключевые слова, в том числе с учётом одной опечатки. Если тема определяется, FastAPI возвращает готовый ответ. В остальных случаях чат показывает подсказку.

При разработке использован [учебный пример Simple Chatbot in Python using NLTK](https://github.com/parulnith/Building-a-Simple-Chatbot-in-Python-using-NLTK). Лицензия шрифта Golos Text находится в `static/fonts/OFL.txt`.
